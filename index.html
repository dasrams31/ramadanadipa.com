Mountain Hiking Route Recommendation System using Content-based Filtering with SBERT and Cosine Similarity

Rama Danadipa Putra Wijaya, Arif Nur Rahman

Developed a mountain hiking route recommendation system using Content-Based Filtering with Sentence-BERT for semantic route-description features, numeric GPX attribute integration, and Cosine Similarity. Evaluated on 39 hiking routes across Java with an average Precision@5 of 0.60 | outperforming TF-IDF at 0.25.
